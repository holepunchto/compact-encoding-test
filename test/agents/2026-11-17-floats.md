# Finish test: the floats, 2026-11-17

A fresh agent was given `CODECS.md` and a list of case inputs, in a directory holding nothing else. It was barred from reading the reference implementation, the fixtures, any library implementing the format, and the rest of this repository. It implemented `float32` and `float64` in plain JavaScript from the document, answered all 25 cases of the two float directories, and reported where the document left it guessing.

## Result

Twenty-five of twenty-five answers identical to the committed fixtures, including every case written to separate two readings: ties to even at 16777217 and 16777219, 4e38 overflowing to `0000807f`, both negative zeros surviving a round trip, and both NaN payload decodes.

The family is implementable from the document. Nothing the run found is a wrong rule: the four gaps below are places the document is silent, and three of them are about NaN.

## What it could not settle from the document

Each of these became an entry in `TODO.md` rather than an edit to either side.

- The width of a `bits` answer. The only worked example is a float64 one, so for a float32 NaN decode `bits` could be the four bytes the same codec writes back, or the eight of the binary64 the reference holds every number as. The run took four; the other reading answers `000000200000f07f` for `float32-nan-signalling`, which is a divergence rather than a declaration.
- How a NaN payload maps between binary32 and binary64. `float-nan-quiet-bit` says the payload survives at both widths and never says how it is carried across. The run implemented a left-aligned mapping; right-aligned is equally available, and no case tells the two apart.
- Whether a NaN keeps its sign bit through an encode, a decode, or a narrowing. No rule mentions it and no case exercises it, so a port decides it alone.
- That a float decoder rejects short input. The Floats section never says so; it follows from `decode-rejects-a-short-width` two sections earlier, under a heading about what a decoder consumes. Both short-input cases rest on that hop, and the run recorded weighing a zero-padded read, which nothing in the Floats section forbids.

## Method

The run is reproducible: copy `CODECS.md` and the `input` fields of the cases to an empty directory, and give an agent with no other context those two files.
